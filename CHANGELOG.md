## [0.1.0] - 2026-07-27

### Added

- A runnable uni-app CLI skeleton using Vue 3, TypeScript, Vite, and Pinia.
- First-class H5 and `mp-weixin` development and production builds.
- Feature-first boundaries, `uni.*` platform adapters, typed configuration,
  and architecture fitness checks.
- Formatting, type, lint, route, dependency-cohort, test-coverage, build,
  and Mini Program package-budget gates.
- Deterministic project and feature scaffolding with template-token and
  generated-project smoke checks.
- Cross-agent guidance, task-routed Agent Skills, specs, and ADR support.
- Cross-tool AI assets in generated projects: `.agents` skills, MCP
  configurations for Kimi Code, Claude Code, Codex, and Gemini CLI, and
  editor-agent bridges.
- An opt-in Weixin runtime AI Alpha profile while keeping the stable DCloud
  cohort as the default.
- A commit-pinned, machine-checked Top 10 uni-app architecture audit and
  evidence-to-implementation decision map.
- Typed public env parsing, HTTP executor contract tests, path-safe route
  and Feature boundaries, and separate main/subpackage output budgets.
- Generator verification covering edge cases and a freshly installed,
  scaffolded, dual-built output project, with a lightweight Windows/Linux CI
  contract.
- Grouped Renovate policy for atomic review of the DCloud compiler and its
  verified Vue/Vite/Pinia peers.
- Open-source release readiness: `SECURITY.md`, Contributor Covenant Code of
  Conduct, issue and pull request templates, README badges, license sections,
  and an MIT `LICENSE` instantiated into every generated project.
