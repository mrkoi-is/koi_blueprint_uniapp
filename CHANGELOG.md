# Changelog

All notable changes to this blueprint are recorded here.

## 0.1.0 - 2026-07-27

- Added a runnable uni-app CLI skeleton using Vue 3, TypeScript, Vite, and
  Pinia.
- Added first-class H5 and `mp-weixin` development and production builds.
- Added feature-first boundaries, `uni.*` platform adapters, typed
  configuration, and architecture fitness checks.
- Added formatting, type, lint, route, dependency-cohort, test-coverage, build,
  and Mini Program package-budget gates.
- Added deterministic project and feature scaffolding with template-token and
  generated-project smoke checks.
- Added cross-agent guidance, task-routed Agent Skills, specs, and ADR support.
- Added an opt-in Weixin runtime AI Alpha profile while keeping the stable
  DCloud cohort as the default.
- Added a commit-pinned, machine-checked Top 10 uni-app architecture audit and
  evidence-to-implementation decision map.
- Added typed public env parsing, HTTP executor contract tests, path-safe route
  and Feature boundaries, and separate main/subpackage output budgets.
- Expanded generator verification to cover edge cases and a freshly installed,
  scaffolded, dual-built output project, with a lightweight Windows/Linux CI
  contract.
- Added grouped Renovate policy for atomic review of the DCloud compiler and
  its verified Vue/Vite/Pinia peers.
